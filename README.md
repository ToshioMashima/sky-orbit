# 天际 · 日地月模拟器

一个中文交互天文网页：在任意经纬度、日期和时间观察太阳与月亮，也可以飞到太空看地球自转、公转和月球运动。无需构建、无需注册、无在线依赖。

## Mac 新手：最快打开方法

1. 如果从 GitHub 下载：点击绿色 **Code → Download ZIP**。
2. 双击 ZIP 解压。**保留完整文件夹**，不要单独移动 `index.html`。
3. 双击 **index.html**，Safari 或 Chrome 就会打开模拟器。
4. 如果系统用编辑器打开它：右键文件 → **打开方式 → Safari / Google Chrome**。

第一次打开也不需要网络。经纬度、日期不会发送到服务器；只有主动点击“我的位置”时，浏览器会申请定位权限。

## 怎么操作

- **地面视角**：拖动环顾，滚轮缩放，也可点击画面后按方向键。首次打开朝向当前可见的太阳或月亮。
- **太阳 / 月亮按钮**：看向并持续跟踪该天体。如果在地下，开启“地球透明”。拖动画面或点击“复位”退出跟踪。
- **经纬度**：拖动滑块，或点击数字直接输入。北纬/东经为正，南纬/西经为负。可快捷选择城市、赤道和南北极。
- **日期 / 时间**：支持 1900–2100 年。时间条可精确拖动到某秒。播放从每秒 1 分钟到每秒 1 周，并自动跨天。
- **时区**：选择固定 UTC 偏移。切换时区保留同一真实时刻；更换地点不会自动更改时区。**夏令时请手动选对应偏移**，例如伦敦夏季 UTC+01:00。
- **当天轨迹**：金色为太阳，银色为月亮。显示所选时区当天 00:00–24:00 的轨迹，每 5 分钟采样，标签为该时区小时。月亮每天会移动，因此轨迹不一定闭合。
- **地球透明**：地面视角显示地平线以下的天体和虚线轨迹；太空视角让地球表面透明。
- **参考面**：青色为天赤道 / 赤道面，紫色为黄道 / 黄道面。地面视角展示平面与天球相交的圆，太空视角展示半透明平面。
- **太空 → 地球附近**：观察自转、日照方向、日月相对地心方向和观测点。
- **太空 → 太阳系**：以太阳为中心看地球公转和月球绕地球运动。
- 下方高度角、方位角始终属于所选**地面观测点**，即使处于太空视角。
- 右上角 **使用指南** 含完整说明。小屏幕上参数面板在画面下方。

## 准确性与示意范围

使用 [Astronomy Engine 2.1.19](https://github.com/cosinekitty/astronomy/tree/v2.1.19)，该库设计目标精度约 1 角分（1/60 度）。这不是对所有天气下观测位置或日出时刻的绝对误差保证。

- 地面位置使用站心坐标，包含月球视差、光行差、岁差章动与日期真赤道，可选标准大气折射。
- 海拔固定 0 米，假设平坦地平线；天气、实际海拔、山地遮挡未建模。
- 读数为天体中心；日出/日落按标准折射下太阳上缘通过理想地平线计算，不随折射开关改变。“无”指所选时区当天没有该事件，例如极昼/极夜。
- 方位角：北 0°、东 90°、南 180°、西 270°。高度角：地平线 0°、天顶 90°。
- 太空使用日期真赤道坐标，黄道面按当日变换计算。地球地图按格林尼治视恒星时自转。月球轨迹采样约 27.32 天，地球轨迹采样约 365.26 天，未假定完美圆轨道。
- **太空距离与天体半径分别缩放**。地球附近模式保留日月相对地心方向；太阳系模式夸大地月距离。不能用画面重叠判断日月食，也不能拿图中距离测量。
- 地面日月图标适度放大，轨迹和读数使用天体中心方向。
- 星点为装饰，不是恒星星表。月相卡片照亮比例为计算值，朝向为示意。

算法文档：[JavaScript API](https://github.com/cosinekitty/astronomy/blob/v2.1.19/source/js/README.md)。

## 可选：通过本机网址打开

直接双击已经足够。若 Mac 已安装 Python 3，也可以：

1. 按 Command + 空格，搜索并打开“终端”。
2. 输入 `cd `（后面一个空格），把解压后的文件夹拖进终端，回车。
3. 输入以下内容，回车：

```sh
python3 -m http.server 8000
```

4. 浏览器访问 **http://localhost:8000**。
5. 关闭服务：在终端按 **Control + C**。

提示找不到 Python 时，直接双击 `index.html` 即可。若 8000 端口被占用，把命令和网址中的 8000 都改成 8001。

## 放到 GitHub，生成分享网址

这是纯静态网页，不需要服务器或构建步骤。

1. GitHub 右上角 **+ → New repository**，起名如 `sky-orbit`，选择 **Public** 并创建。
2. **Add file → Upload files**，上传 `index.html`、`style.css`、`app.js`、`scene.js`、`astronomy-core.js` 和整个 `vendor` 文件夹。可上传完整项目，排除个人文件和测试输出。
3. 仓库 **Settings → Pages → Build and deployment**。
4. Source 选 **Deploy from a branch**。
5. Branch 选 **main**，文件夹选 **/(root)**，点击 **Save**。
6. 等待数分钟，会显示类似 **https://你的用户名.github.io/sky-orbit/** 的网址。

引用均使用相对路径，支持 GitHub 项目子路径。GPS 定位在 HTTPS 环境中可请求浏览器许可；不可用时仍可手动选择地点。

链接也支持参数，例如：

```text
?lat=39.9&lon=116.4&date=2024-06-21T04:00:00Z&view=ground
```

`date` 为带 `Z` 的 UTC 时刻；`view` 为 `ground` 或 `space`。

## 开发与验证（普通使用不需要）

不需要安装 npm 依赖。已安装 Node.js 时可运行：

```sh
node --test tests/astronomy.test.cjs
```

覆盖时区跨日与闰日、NREL SPA 独立太阳位置参考、二至日、极昼极夜、轨迹边界、月球视差、地面/太空坐标变换、大气折射、2024 年达拉斯日食附近的日月对齐。

太阳参考：[NREL/TP-560-34302](https://docs.nlr.gov/docs/fy08osti/34302.pdf) 标准案例。参考气压与海拔不同，允许 0.02° 差异；本项目未嵌入 NREL SPA 代码。

`tests/browser-check.cjs` 为可选浏览器检查，需 Playwright 和 Chrome。它检查桌面、手机、`file://` 离线、日期时区、透明图层、视角和播放。`PLAYWRIGHT_MODULE` 可指定已有 Playwright 包目录，`SKY_BASE_URL` 可指定预览网址。
